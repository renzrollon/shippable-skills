# Productivity

Daily non-code workflow tools.

**User-invoked**

- **[session-retro](./session-retro/)**: Retro the current session. Score it against session shapes, flag token waste, propose wire-ins into the skills this conversation called.
- **[product-spine](./product-spine/)**: Help an engineer act as product owner: suggest work threads, then draft, review, and capability-check the one-pager, epics, and briefs. Writes artefacts, never code.
- **[session-handoff](./session-handoff/)**: Save where this session stands to a handoff file before a context reset, so the next session or agent resumes without re-deriving decisions.

**Model-invoked**

- **[session-primer](./session-primer/)**: Brief a fresh session in one read-only pass, from git state, open plan checkboxes, the newest handoff file, and the instruction file.
