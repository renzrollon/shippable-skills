# Engineering

Daily code work.

**User-invoked**

- **[bump-release](./bump-release/)**: Bump the project's version in every manifest at once, then commit, tag, push, and cut a release, so no manifest keeps a stale version.

**Model-invoked**

- **[fix-tests](./fix-tests/)**: Discover and persist how a project's tests run, then run the suite and repair failures by root cause: cluster failures by error signature, fix the shared cause once, and assert no test was weakened.
- **[explore](./explore/)**: Deep read-only reconnaissance before a change is designed. Fans out parallel investigators across subsystems, then synthesizes one picture and, in an autonomous run, writes a durable brief.
